# Деловой этикет по-русски · 俄语商务交际礼仪

Учебный статический сайт по теме **«Речевой этикет в письменной деловой коммуникации в русской и китайской культурах»**.

Сайт предназначен для **китайских студентов, изучающих русский язык на уровне A2–B1**. Все материалы доступны без регистрации, работают на телефоне и компьютере, не требуют сервера, базы данных и внешних библиотек.

---

## 1. Что уже готово

| Компонент | Объём | Где находится |
|---|---|---|

| Иллюстрации | 1 большая иллюстрация + 6 иллюстраций групп + 28 SVG-иконок | `assets/`, SVG-спрайт в `index.html` |

| Диалог | 12 реплик, три участника, перевод и аудио | раздел «Письма и диалог» |
| Тест | **12 вопросов**, проверка сразу после ответа, счёт, процент, разбор ошибок, лучший результат | раздел «Тест» |
| Культурное сравнение | 8 аспектов + 5 типичных ошибок | раздел «Культура» |
| Адаптивность | десктоп, планшет, телефон (проверено на ширине 390 px) | — |

**Особенности:**
- двуязычный интерфейс (русский + китайский);
- ударения в русских фразах;
- аудио при нажатии на динамик (при поддержке браузера — резервное озвучивание через Web Speech API);
- фильтр по группам и поиск по русскому/китайскому тексту;
- тест можно проходить повторно, лучший результат сохраняется в `localStorage`;
- клавиатурная навигация, `aria-live` для обратной связи, поддержка `prefers-reduced-motion`;
- нет внешних шрифтов и CDN — сайт работает офлайн и не зависит от доступности Google Fonts.

## 2. Соответствие плану разработки

### 1. Выбор контингента

**Китайские студенты, изучающие русский язык, уровень A2–B1** (элементарный — средний этап).

Почему:
- A2 позволяет читать короткие деловые фразы и понимать перевод; B1 — работать с письмами и диалогом;
- китайские студенты нуждаются в сопоставлении русских формул с китайскими (您, 尊敬的, 此致敬礼 и т. п.);
- интерфейс и пояснения даны на русском с китайскими переводами, чтобы не снижать языковую среду, но сохранять опору на родной язык.

### 2. Выбор тематики

Выбраны **языковой и социокультурный компоненты**:
- языковой: формулы речевого этикета, структура письма, вежливые просьбы и отказы;
- социокультурный: сравнение русской и китайской традиций, типичные ошибки, «сохранение лица».

Литературный компонент сознательно не включён: тема исследования — деловая письменная коммуникация, а не художественная литература.

### 3. Компоненты сервиса и порядок элементов

| Компонент | Реализация | Количество |
|---|---|---|
| Словарь | карточки: фраза с ударением, перевод, пример, помета регистра, аудио, иконка | 36 |
| Иллюстрации | SVG-иллюстрации групп и иконки для карточек | 7 + 28 |
| Аудио | синтез речи Milena (macOS), формат M4A/AAC | 50 файлов |
| Письма | запрос китайской компании и ответ российской, с переводом и выделением формул | 2 |
| Диалог | первая встреча в офисе, 3 участника | 12 реплик |
| Тест | 12 вопросов: формулы, грамматика, стиль, культура, структура | 12 |
| Культурные заметки | таблица сравнения и частые ошибки | 8 + 5 |

**Порядок элементов** подчинён логике делового письма:
1. приветствие и обращение;
2. знакомство и компания;
3. просьба и предложение;
4. согласие, отказ, извинение;
5. структура письма;
6. благодарность и вежливость.

Сначала студент получает **образцы** (словарь, письма, диалог), затем **тренировку** (тест с мгновенной проверкой) и **обратную связь** (разбор ошибок). Внутри теста вопросы перемешаны по темам, чтобы проверить выбор формулы в новой ситуации, а не только узнавание списка.

### 4\*. Выбор сервиса для размещения

Выбран **статический хостинг** (GitHub Pages / Cloudflare Pages / Netlify / Vercel). Обоснование:
- сайту не нужны серверная часть и база данных;
- публикация бесплатна, не требует установки;
- страница быстро загружается и работает на слабых устройствах;
- отсутствуют внешние зависимости, поэтому сайт можно открыть даже локально;
- обновление контента — замена файлов или правка `js/data.js`.

Ограничение: лучший результат теста хранится только в браузере студента. Для полноценного личного кабинета и статистики преподавателя понадобится backend (например, Supabase/Firebase), но для учебного проекта это не обязательно.

### 5\*. Размещение

Сайт готов к публикации. Пошаговая инструкция — в разделе 5 ниже. Для аудитории в материковом Китае важно проверить доступность выбранного хостинга: GitHub Pages может работать нестабильно; надёжнее Cloudflare Pages или китайский объектный хостинг (Aliyun OSS / Tencent COS) с CDN. Домены, размещённые в материковом Китае, требуют ICP-регистрации.

## 5. Как опубликовать сайт (сделать доступным всем)

### Вариант A. GitHub Pages

1. Создайте публичный репозиторий, например `ru-business-etiquette`.
2. Загрузите **содержимое папки** `ru-business-etiquette` в корень репозитория так, чтобы `index.html` лежал в корне.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Нажмите **Save** и подождите 1–2 минуты.
6. Адрес будет вида `https://<ваш-логин>.github.io/ru-business-etiquette/`.

### Вариант B. Cloudflare Pages (удобно для быстрой публикации)

1. Войдите в Cloudflare Dashboard.
2. **Workers & Pages → Create → Pages → Upload assets**.
3. Укажите название проекта и загрузите папку `ru-business-etiquette` (или zip).
4. Нажмите **Deploy**. Получите адрес `https://<project>.pages.dev`.

### Вариант C. Netlify Drop

1. Откройте <https://app.netlify.com/drop>.
2. Перетащите папку `ru-business-etiquette`.
3. Получите временный адрес; чтобы закрепить сайт, войдите в аккаунт и нажмите **Claim**.

### Вариант D. Vercel

1. Установите Vercel CLI или войдите в панель.
2. Импортируйте папку как статический проект (Framework Preset: **Other**).
3. Build Command оставьте пустым, Output Directory — `.`.

### Если сайт нужен в материковом Китае

- Проверьте доступность GitHub Pages/Cloudflare из целевой аудитории.
- Для гарантированной скорости используйте китайский объектный хостинг (Aliyun OSS, Tencent COS) + CDN; для домена в материковом Китае нужна ICP-регистрация.
- Сайт не использует внешние CDN, поэтому после переноса достаточно загрузить папку целиком.

### QR-код для аудитории

После публикации сгенерируйте QR-код на полученный адрес — так студентам удобно открыть сайт с телефона на занятии.

## 6. Как менять контент

Весь учебный материал собран в `js/data.js`:

| Константа | Что содержит |
|---|---|
| `VOCAB_GROUPS` | 6 групп, фразы, переводы, примеры, пометы, иконки |
| `EMAILS` | два письма: метаданные, русский и китайский текст, формулы |
| `DIALOGUE` | участники, реплики, переводы, формулы |
| `QUIZ` | вопросы, варианты, правильный ответ, объяснение на двух языках |
| `CULTURE_ROWS` | строки сравнительной таблицы |
| `MISTAKES` | типичные ошибки |

### Добавить фразу

Скопируйте объект в нужную группу `VOCAB_GROUPS`:

```js
{
  ru: "Но́вая фра́за",
  zh: "新的短语",
  exRu: "Пример употребления.",
  exZh: "例句。",
  register: "official", // official | neutral | spoken
  icon: "i-letter"      // id иконки из спрайта в index.html
}
```

Затем добавьте аудиофайл `assets/audio/vocab-<id-группы>-<номер>.m4a` (например, `vocab-request-7.m4a`). Если файла нет, кнопка автоматически использует Web Speech API.

### Заменить аудио

Перезапишите файлы в `assets/audio/` файлами с теми же именами (AAC/M4A). Можно записать голос преподавателя или носителя языка — это предпочтительнее синтеза.

### Изменить количество вопросов

Тест автоматически считает `QUIZ.length`. Но тексты «12 вопросов» в hero, заголовке раздела и описании нужно обновить вручную в `index.html`.

### Изменить количество фраз

`TOTAL_PHRASES` считается автоматически, но число `36` в hero и паспорте проекта задано вручную — обновите его в `index.html`.

### Иконки

SVG-спрайт находится в начале `index.html` (символы `i-letter`, `i-people`, `i-chat`, `i-sun`, `i-person`, `i-book`, `i-building`, `i-globe`, `i-handshake`, `i-card`, `i-envelope`, `i-question`, `i-doc`, `i-calendar`, `i-check`, `i-cross`, `i-clock`, `i-smile`, `i-heart`, `i-clip`, `i-signature`, `i-star` и служебные). Новую иконку добавьте как `<symbol>` и используйте её `id` в данных.

## 7. Методическая логика

- **Уровень A2–B1.** Короткие фразы, перевод, примеры, ударения, аудио; пояснения не перегружены терминами.
- **Коммуникативный подход.** Каждая фраза привязана к речевой задаче: поприветствовать, представиться, попросить, отказать, завершить письмо.
- **Наглядность.** Иллюстрации групп, иконки, цветовые пометы регистра, таблица сравнения.
- **Социокультурное сопоставление.** Русская прямота и китайская косвенность, обращение по имени-отчеству и по фамилии+должности, «сохранение лица».
- **Обратная связь.** В тесте правильный ответ подсвечивается сразу, объяснение даётся на русском и китайском; в конце — разбор ошибок.
- **Повторяемость.** Тест можно проходить несколько раз, результат сохраняется локально.
- **Доступность.** Семантическая разметка, клавиатура, контраст, адаптивность, отсутствие внешних ресурсов.

### Авторство материалов

Тексты писем и диалога составлены специально для проекта на основе типовых формул русской деловой переписки. Иллюстрации — оригинальные SVG, созданные для сайта; внешние изображения и шрифты не используются, поэтому отдельные лицензии на графику не требуются. Аудио синтезировано голосом Milena; его можно заменить записью преподавателя.

### Ограничения

- аудио синтезировано (Milena); для публикации в университете лучше заменить записью преподавателя;
- тест проверяет узнавание и выбор, но не свободную письменную продукцию;
- нет регистрации и статистики преподавателя;
- китайские переводы выполнены как учебные; перед публикацией желательна проверка носителем языка;
- видео не используется; при необходимости можно добавить короткие видеозаписи диалога.

## 8. Проверка

- HTML и JS проверены на синтаксис;
- в Chrome (desktop) пройдены сценарии: тест 12/12, тест 0/12 с разбором, повторный запуск, поиск по русскому и китайскому, переключение перевода, аудио;
- проверена адаптивность на ширине 390 px: нет горизонтальной прокрутки, карточки в одну колонку, таблица превращается в карточки;
- проверено, что все 50 аудиофайлов и 6 иллюстраций групп присутствуют;
- внешние сетевые запросы отсутствуют.
